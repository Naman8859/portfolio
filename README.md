# Personal Portfolio Website

A modern and responsive portfolio website built to showcase my skills, projects, and journey as a Frontend Developer.

## 🚀 Live Demo

🔗 https://namansinghchauhan-portfolio.netlify.app/

## 📌 About The Project

This portfolio website represents my learning journey in web development. It highlights my projects, technical skills, development process, and growth as a frontend developer.

The website is fully responsive and designed to provide a clean and engaging user experience across different devices.

## ✨ Features

* Responsive Design
* Interactive Navigation Menu
* Project Showcase Section
* About Me Section
* Development Process Section
* Social Media Integration
* Mobile-Friendly Layout

* JavaScript
* Git & GitHub
* VS Code
